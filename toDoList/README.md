# React To-Do List

A simple to-do list app built with React as a practice project.

## Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Completed tasks are crossed out
* Scrollable task list for larger numbers of tasks

## Built With

* React
* JavaScript
* CSS
* Vite

## Purpose

This project was created to practise React fundamentals including:

* `useState`
* Passing props
* Event handling
* Updating arrays in state
* Rendering lists with `.map()`
* Removing items with `.filter()`
* Controlled inputs
* Conditional styling with CSS
